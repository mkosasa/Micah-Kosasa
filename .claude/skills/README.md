# Skills

Claude skills used in this repo will live here, one folder per skill.

Scheduled cloud routines are recorded here too — one folder per routine,
with a `README.md` (what it does + live config) and a redacted `prompt.md`
mirror of the live prompt.

## Index

| Folder | Kind | What it is |
|---|---|---|
| [mba-class-notes](mba-class-notes/) | skill | DLEMBA class-recording transcript → house-style study notes, filed as a Google Doc in the matching class folder (also runs daily at 8am HST) |
| [mba-team-meeting-notes](mba-team-meeting-notes/) | routine | Weekly: MBA team Zoom meeting → filed notes + group email, with due dates cross-checked against the class syllabi |
